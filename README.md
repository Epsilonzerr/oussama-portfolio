# Oussama Moustarzik — Portfolio

Modern dark portfolio for a Software & AI Engineer.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before deployment

1. Add your professional email in `components/Portfolio.tsx` (`mailto:`).
2. Add your LinkedIn URL.
3. Put your CV in `public/` and add a download button if desired.
4. Replace or enrich project links in `data/portfolio.ts`.

## Suggested deployment

Deploy directly to Vercel after pushing the folder to GitHub or GitLab.
